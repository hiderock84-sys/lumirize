## 公開元と変更方法
GitHub Pagesの公開元は `cursor/lumirize-official-homepage-60e8` です。デフォルトブランチの `main` とは履歴が分岐しています。デフォルトブランチ名から公開元を推測せず、直近のPages実行・デプロイログを確認してください。

公開元の最新コミットから作業ブランチを作成し、変更をPRで確認してから同じ公開元へ統合します。古い別デザインのPRを一括統合しないでください。共有JavaScriptを変更した場合は、読み込み元HTMLのバージョン付きURLも更新します。

上記は通信を模擬したテストで、実メールを送信しません。画面検証では、5言語、入力保持、入力エラー、送信待ち、結果不明、成功、返信不要、スマートフォン幅とPC幅を確認します。送信待ち中は希望言語以外の入力を固定し、言語を切り替えても再送しません。模擬結果と実際のメール到着は区別します。

公開後に問題が見つかった場合は、原因となった統合コミットだけを公開元でrevertし、Pagesの公開成功と実画面を確認します。force pushやmainへの公開元変更は通常の復旧手順に含めません。料金・運営規程・職員体制は現行資料と照合してから変更します。
